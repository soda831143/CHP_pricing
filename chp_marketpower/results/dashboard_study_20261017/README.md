# 118-G11：独立 Q500 价格查询摊销实验

日期：2026-10-17。基线代码版本：`cd864cc7f7a880e50108eb9c12fd84ef4f9d99f3`，本轮未改变定价算法或计时入口。网页代码不是求解算法的替代。

## 固定协议

原有 `118_sparse_bracket_0to50` 完整地图，IEEE118 / G11 / 全日统一绝对加数 / tight PTDF / 24h / 3段增量成本 / aggregate-output 网络表示。范围0–50%，reference slope=36.33 $/MWh。重新启动一条完整500次查询流，不接续或拼接旧200次会话。

```powershell
python benchmark_oracle_queries.py --oracle-dir results/scope_study_20261016/118_sparse_bracket_0to50 --queries 500 --skip-fresh --order shuffled --seed 20261018 --record-trace --output results/dashboard_study_20261017/trace_118_G11_q500.json
```

Q、随机种子、范围及停止点由该调用固定，不依照是否出现交叉而扩展。查询是在参数域2.5%–97.5%内部的500个等距点，再以固定种子乱序。因为等距点依赖Q，不能把这次前200个点解释为旧Q200的前缀。保留全部500个实测累计点和原始报价。

环境记录于实验完成后的同一工作站：Python3.13.5、COPT/coptpy8.0.6、NumPy2.1.3；未另行跑新的建图计时。原离线成本来自已归档建图，非本次500次求解期间重测。网页导出/开发不启动并行优化；测量完成后才运行新增 UC/LOC 测试。

首次**实测离散前缀**摊销点为Q=224，不是连续插值估计。Q=500时累计时间比 **2.000643×**。Oracle500次在线查表共0.006207秒，另计加载0.006249秒及原离线建图/后处理。表中的Oracle接近水平但使用实际查询前缀，未替换为人为常数。

最大价值误差 **5.58793545e-9美元**，满足1e-6声明阈值。选定合法价格与直接求解器价格的最大分量差约 **0.585599美元/MWh**；这是对偶选择不同，不能要求价格逐点相同，也不能据此把它算作价值误差。完整对偶选价合法性沿用原地图各区间的独立验证，不用价格相等替代对偶可行性/强对偶。

本次单工作负载结果支持“固定模型重复定价可摊销离线成本”，不支持所有查询量、所有方向、所有硬件均加速，也不包含物理 UC、利润或全市场重新运行的耗时。原200次未摊销结果保留，不覆盖已有论文Fig.2。
