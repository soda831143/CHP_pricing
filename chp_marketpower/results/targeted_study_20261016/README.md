# 30/118 节点定向补充实验

完整目标、假设、理论和结果解释见 [定向实验方案](../../TARGETED_STUDY_20261016.md)。本轮无6节点研究结果，也未修改其历史归档。

- `contrasting_generator_plan.json`：在新建图前固定的基准运行选机规则与数据，选择30-G2。`baseline_30_physical.npz`为基准全系统方案。
- `30_G2_bracket_0to50/`：15个原始CHP点、8个价值/选价区间，完整原始见证、精简查询文件、压缩审计、14个内部点直接验证。
- `query_30_G2_q1000.json`：固定1000个乱序报价，实测持久重优化115.33s，Oracle总5.80s。
- `query_118_q200.json`：固定200个乱序报价，持久重优化278.06s，Oracle总311.60s，尚未摊销。离线成本来自前轮118完整地图，不是本轮重新建图计时；单次实测，无方差或临界查询数主张。
- `30_G1_signed_price_impact.json`：从同一双向地图提取价格变化的正负号、节点、时段，不重新求解CHP。
- `30_G1_profit_0to50/physical_plans.npz`：33次UC求解的完整系统出力、启停、成本线、全局下界及求解状态；每次成功求解后保存，顺序为实际发现顺序而非按报价排序。
- `30_G1_profit_0to50/physical_regions.json`：利润计算前保存的物理区间证据；17段，100%覆盖。其`profit_assessment_status=not_started`是阶段记录，不应代替最终利润报告。
- `30_G1_profit_0to50/profit_range.json`：完成的99个联合区间、116条报价/方案端点候选、100个不同报价的自调度、利润分解及声明的物理边界选择。最优候选约31.451766%，额外利润约7811.56美元；最大值取得依赖边界选择，精确模型下的共同上确界解释见方案第4.1节。
- `30_G1_profit_0to50/direct_validation.json`：17个区间中点及最优点/两侧，共20个独立UC检查；显式保留边界处求解器选择与声明选择的利润差别。

本轮查询/计时按顺序执行，无其他大型优化并行。G2与118查询批次种子20261017；G1前轮种子20261016，不将跨机组时间差当作配对性能检验。

`test_tmp_*`为沙箱内测试夹具，日志为运行诊断，均不归档。测试因系统默认临时目录权限受限时，可在项目内指定一个**新**临时目录：

```powershell
python -m pytest -q tests ../chp_energy/tests --basetemp=results/new_test_tmp
```

运行研究入口仍需COPT及相邻`chp_energy`。118原始`oracle.npz`超过GitHub单文件常规限制，仍仅保留本地，本轮没有伪装为已上传；重现实测可按前轮构造入口重建。G2及物理UC完整见证规模小，已正常归档。
