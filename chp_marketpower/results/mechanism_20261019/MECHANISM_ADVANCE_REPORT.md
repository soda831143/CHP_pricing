# 可替代运行方案的成本竞争如何形成策略获利临界值

2026-10-19。接续10月18日的机制恢复研究；依据用户提供的最初导师意见分析与266f281阶段性评审开展。本轮保留原Oracle、选价路径和既有档案，优先完成临界预测与完整获利路径，不扩展指标排名或策略维数。

**当前案例中，G5提前在线替代G1的额外真实运行成本，与它所减少的G1报价暴露，共同决定物理执行切换阈值。空载成本扰动能事先预测阈值移动；启动次数相同的成本扰动则不移动该阈值。** 全局UC下界验证了这一局部替代机制，而完整路径核算进一步说明该阈值与整个策略收益的关系。

## 2. 成本交点给出事前预测

固定原始完整物理方案A/B，真实系统成本分别为184,189.786589与185,577.133581美元，G1增量报价暴露分别为1,464.060870与1,358.991304 MWh。故

\[
\delta^*=\frac{C_B^0-C_A^0}{D_A-D_B}
=\frac{1387.3469913043373}{105.0695652173913}
=13.204080443598345\ \mathrm{USD/MWh}.
\]

原归档临界值为13.204080443599175，差约8.3e-13。成本差独立由逐机组、逐小时真实成本重构，而非用已知阈值反推。

|B相对A的真实成本变化|美元|
|---|---:|
|G1|−4,416.899194|
|G3|−1,150.503814|
|G5|+6,954.750000|
|其他机组|约0|
|系统合计|+1,387.346991|

G5从第6小时启动改为第1小时启动，多在线5小时、两套均启动一次。模型cost_nl为C(Pmin)，即每开机时段的最低出力/固定运行成本项；对其增加ε美元/在线小时，既改变G5真实成本，也改变其真实申报成本，未改变G1的策略报价方向、物理约束或初态。

固定A/B下预先预测：

\[
\delta^*(\varepsilon)=\delta^*(0)+\frac{5\varepsilon}{105.0695652173913},
\qquad \partial\delta^*/\partial\varepsilon=0.047587519655714644.
\]

两条候选线相交本身不足以证明全局UC阈值。因此每个情景独立求δ预测值及其±0.001处的全局UC，并用候选方案到全局下界的差验证左侧A、右侧B。候选线为上界，端点全局下界的弦为下界，二者相合才支持整个窄邻域的共同最优性。

右列均按各自改变后市场的真实报价基线计算；只报告这个固定位置的利润，没有在改变后的市场重建全域价格地图，因而不是各情景全域最大市场力。

另行在运行前声明负对照：G5真实启动成本增加50美元/次。A/B均启动一次，预测相对成本差和阈值不变。三次全局UC检查支持该预测，最大候选下界差8.73e-11美元。它是物理成本机制的负对照，不是战略startup-adder报价实验，也没有新增价格/利润结论。

## 3. 解释全部7,811.56美元，而不是一个临界差额

保持归档CHP选价和物理区间规则，从δ=0走到原最有利候选δ*。复用已有83个价格分段和17个物理区间在这段路径上的37个联合区间；只重新求38个单机最优自调度，不新增价格扫描、CHP建图或物理UC发现。

每个联合区间的共同SS方案在左右端点均达到保存的全局上界，以负自调度盈余复用已有凹成本区域算法验证。由此可逐段计算价格与暴露通道积分，在物理切换处单独加入δΔD。

|路径账目|美元|
|---|---:|
|自调度出力加权价格通道积分|+8,741.602193|
|连续执行暴露通道积分|−29.225308|
|δ=9.218100544处物理跳变|−769.350687|
|δ=11.393501130处物理跳变|−131.471096|
|相对真实报价的总利润增加|+7,811.555102|
|整条路径重构残差|约−5.50e-9|

所有区间的SS共同最优性差小于1e-6美元，逐段账目最大残差约1.15e-8美元。这是声明报价路径上的精确形式、数值验证的会计分解，各项不是相互独立的因果处理，正负通道可以抵消，不能作风险指标的简单份额。

在原最有利临界点，路径终点采用左侧较高暴露方案，因此没有把随后切到B的−1,387.35美元加入到达该点的收益中。该差额是同报价的两执行比较，不是7,811.56美元的一个可直接归因百分比。

最有利策略机会也不要求精确命中并列点：原δ*−0.001已有7,810.84美元额外利润。当前结论绑定既有合法选价和执行规则，不声称所有价格选择下的非线性利润界。

## 4. 网络处理改变的是哪些候选方案能处于下包络

原E4只放宽第30条线路，原A/B仍物理可行，真实成本截距与G1暴露均不改变，它们的两线交点因此不变。然而在原临界左右两个固定报价，A/B已比处理后最优UC分别贵约2,196.5–2,196.6美元，失去全局最优地位。

新最优调度的第30条线路最大绝对流量约39.00545 MW，超过原20.8 MW限额，在原网络不可行。故这一控制比较的机制是：扩大可行域引入原来被排除的低成本替代方案，改变整个成本下包络；不是同一A/B对的成本截距或暴露斜率被线路容量直接改写。

原E4六组UC/CHP/LOC与八个方向端点保留。本轮只重构其物理成本、流量、可行性和归档全局下界，没有再运行一个新的网络场景或宣称获利对线限单调。

## 5. 定义、论文与可支持的决策

Price-setting leverage指报价改变价格的能力；settlement-based incentive指申报成本、LOC和执行差异引起的利润激励；profitable strategic deviation指相对真实报价的正额外真实利润。本文若使用可获利市场力，操作性定义限定为声明策略集合内额外利润的上确界/最大值，不把全部获利都描述为电价操纵。

在真实报价的实际结算右导数存在且为正时，它提供足够小正加价获利的局部充分条件。原E2的G1右导数约509.400343即为该条件的一个实例；非正导数不能排除远处获利。该条件未升级为跨机组监管筛选有效性。
