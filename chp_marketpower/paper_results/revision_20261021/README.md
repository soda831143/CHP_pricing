# 从市场直觉到可检验结论：第三版定向深化

日期：2026-10-21。依据用户提供的对026590d的再评审，优先完成最优报价暴露单调性、同价不同执行的利润差异，以及线路30干预下的报价响应对照。本轮没有调用优化器、重跑计时或增加主图。原始档案保持不变。

“价格影响与获利不同”“替代限制获利”“网络和时序塑造机会”是研究动机，不能单独作为创新结论。反直觉现象也不能替代与已有文献的贡献比较。本轮将主张改为有明确条件、数量预测及可否证边界的结果。

## 理论与决策对象

1. **固定可行域内的物理切换损失。** 固定其他报价，目标成本为C0(s)+δQ(s)，任意两个不同δ下的全局最优执行满足Q(δ2)≤Q(δ1)。这是标准参数优化的性质。将其接到完整申报LOC恒等式，若选价在非负切换报价b处连续，则纯物理切换的利润跳变J=b(Q+−Q−)≤0。它约束跳变的方向，不声称区间内利润单调，也不约束改变网络后的跨情景利润排序。
2. **同价不同执行的精确差额。** 所有其他机组按实际成本报价时，在同一报价、同一合法选价和同一最优申报系统成本下，ΠA−ΠB=δ(QA−QB)=CB−CA，其中C为实际系统总成本。这里既不是G1自身成本差，也不是CHP凸化成本差。ISO的申报成本最优性不能确定生产者的实际利润。真实报价下差额归零。
3. **替代门槛的预测及适用检验。** 既有G5在线费用扰动预报斜率0.04758752，四个指定扰动受全局UC支持；启动次数相同使启动费用对照预测为零。线路放松后原A/B交点不动但第三套可行方案胜出，说明两线交点只有经过全局最优性检验才是实际切换门槛。成本比例公式本身不是新优化理论；可检验的预测、失效条件与结算衔接是本文使用它的实质。

## 新完成的数据分析

读取六组已归档完整CHP/物理UC/申报LOC记录：两种网络，各自真实报价及原临界点左右0.001 USD/MWh。每个网络均用自己的真实报价基准。使用原始30节点×24小时价格数组，不插值新报价，不复用原网络价格作为放松网络结果。

对于每个节点/小时及两个固定报价，输出Δδλ^S=λ^S(δ)−λ^S(0)，再计算放松网络减原网络的响应差。这里是确定性的情景对照，不是统计差分估计；也不将网络改变分解成互相独立的因果份额。

在δ=13.203080443599175 USD/MWh，得到：

|相对各自真实报价基准的变化|原网络|放松线路30|放松减原网络|
|---|---:|---:|---:|
|G1发电量/MWh|−95.000000|−157.495652|−62.495652|
|能量收入/USD|4384.878147|2257.028695|−2127.849452|
|Uplift/USD|−578.342830|−518.418916|59.923914|

因此，579.843731=−2127.849452+59.923914+2647.769270美元。这个结果不只是“总利润与额外利润不同”：在该固定报价下，发电替代更多，额外利润也更大；主要的账目变化是更大的实际成本节约，足以抵消较少的增量收入。总利润仍从45100.15降至40302.15美元，因为真实报价基准也从37289.31降至31911.46美元。不能据此声称放松网络的全域最大市场力更大。

另外，读取17个共同物理区域的完整方案成本线，核查16处边界：报价暴露全部下降，纯物理利润跳变全部为负；每处跳变恰等于负的实际系统替代成本。最大申报成本交点残差3.64e−11美元。这里只检查固定共同方案之间的纯物理差额；完整利润曲线仍包括随报价变化的价格和自调度。

## 现在能回答什么、下一步由什么触发

本文的核心是连续报价评价能力，以及给定选价和结算规则下可计算的替代—利润关系。它可以判断何时两套执行的利润不同、替代何时发生、同一网络内物理切换的损失方向，以及网络变化是否真的降低某个报价的额外利润。

对导师汇报时，最值得检验的说法是“替代改善是否足以判断策略获利下降”。本例在同一报价处给出了反例，并用完整账目解释为何方向相反。它为网络干预评价提供一个可执行判断：比较干预前后各自真实报价到策略报价的收益变化，不能用更少的战略出力、较低的能量价格或较低的总利润替代这一步。这是一条评价规则的实证反例，不是对所有网络规划方案的排序。

本轮不提出“已经识别G1市场力根本来源的全部因果占比”。必需总出力、增量报价暴露、价格影响与实际获利分别保留；未计算最小报价暴露，也未把整机移除不可行变成获利排名。只有当论文决定检验“必要增量暴露是否预测报价收益”时，才需要预先规定机组及对照条件，开展少量新的优化求解。当前网络问题已能用既有数组回答，不触发追加求解。
