# 替代门槛何时有效：成本与网络的机制区分实验

2026-11-02。依据用户提供的第三版创新性评审，本轮检验一个具体判断：已识别的G1–G5替代门槛，在运行成本或输电条件变化后是否仍然控制物理出清。采用事先固定的2×2设计，完成后停止扩展实验。

## 设计与预测

两种网络为原网络和既有线路30放松网络；G5实际在线成本分别增加0和5美元/在线小时。后者沿用已有独立扰动值，不改变G1的报价方向。G1仍采用全天统一增量报价，实际成本、申报LOC和初态约定保持一致；每个网络/成本条件都使用自己的真实报价利润基准。

在新求解前保存 `results/competition_regimes_20261102/protocol_before_run.json`，固定：

- 报价一：13.203080443599175 USD/MWh，即原A/B门槛左侧0.001。
- 报价二：13.441018041876918 USD/MWh，即成本增加5美元后的预测A/B门槛左侧0.001。
- 冻结竞争方案C：既有放松网络在报价一的完整物理方案，尚未运行新条件时就已选定。
- 预算：最多5次物理UC、6次CHP、6次单机自调度，600秒；每个新点独立冷启动定价，保留全量对偶、物理出力、自调度见证和检查点。

预测一：原网络A/B若仍相邻全局最优，其门槛由13.2040804436移动到13.4420180419。该关系的原网络全局UC验证已存在，不重复求解。

预测二：放松网络中的C可能排除A/B。先用其冻结成本线，在δ的0和20.991端点、ε的0和5端点检查C与A、B的成本差。若所有差额严格为正，则不论C是否为全局最优，A/B在整个矩形内均不可能最优。这一预测在求解前已记录。

## 结果：门槛移动与竞争方案排除

完整方案的G5在线时长分别为A的19小时、B的24小时、C的18小时。C的线路30最大潮流约39.01 MW，超过原网络20.8 MW限制；它在原网络不可行，在放松网络可行。

四角检查的最小成本优势为 **1635.464037952188美元**。因为冻结方案之间的成本差对δ、ε均为仿射函数，得到严格的范围结论：在放松网络、δ∈[0,20.991]、ε∈[0,5]下，C始终比A和B便宜。**这排除了原A/B门槛在该范围内控制出清的可能性；没有证明C在整域都最优。**

在原A/B交点，C相对两者的优势为：ε=0时2196.58004776美元，ε=5时2211.69136118美元。A/B交点因成本变化而移动，但线路放松后它们已经不在最优成本下包络上。

新UC求解在两个指定报价和两种成本条件下均支持同一C方案，逐时p和u与冻结方案一致至1e−7内。原网络在报价二，则由ε=0的B变为ε=5的A；其G1报价暴露从1358.991304变为1464.060870 MWh。放松网络四个策略报价点的暴露均为1421.565217 MWh。

## 可以沿用什么判断

识别替代门槛后，先检查原方案是否仍然在全局最优成本下包络上。A/B在交点及相邻侧继续最优时，可用运行成本差预测门槛移动。若存在严格便宜且物理可行的C，则应排除该门槛并重新评价价格和结算。四角检验为固定方案提供一个便宜的排除办法，不依赖重新扫描完整报价域。

利润恒等式和非正切换推论在这个判断中解释执行的结算效应；本文不将其重新包装成首次发现的利润分解或参数优化理论。最小必需发电量不随当前策略方向变化，而报价收益随方向变化；本文不据此开发新结构指标或开展机组排名。
